Upload a spreadsheet

Excel (.xlsx, .xls) or CSV. One row per event, with a header row. Columns are matched automatically and you can change the matching below.

Suggested columns: Date End date (optional, for trips and other multi-day events) Title Description Category Place. Dates like 2005, 3/2005, 3/14/2005, March 2005 or 2005-03-14 all work.

Import Facebook posts

Pick up where you left off

Facebook doesn't let apps read posts directly, so use Facebook's own download:

  1. On Facebook, open Settings → Accounts Center → Your information and permissions → Download your information.
  2. Choose the profile, then Specific types of information → Posts.
  3. Set Format: JSON, Date range: All time, Media quality: High.
  4. When Facebook emails you, download the .zip and drop the whole .zip below.

The file is read in your browser. Only post text is sent to Claude for review, never photos.
